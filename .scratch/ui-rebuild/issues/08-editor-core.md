# 08 编辑器工作区（桌面编辑模式）

Status: ready-for-agent

先读 [实施指南](../implementation-guide.md)。原型：`prototype/js/screens/editor.js`、`editor/{model,viewport,reference,panels,source,catalog}.js` + `styles/screens/editor.css`；截图 `prototype-final/09–11`、`evidence/prototype/ce-*`。

## 范围

- `/app?id=` 编辑器为 100dvh 固定工作区（无站点导航，不整页滚动）。**只换界面层**：现有 `Workbench` 的状态机、生成 Worker、撤销重做、自动保存与同步、原图参照几何（BeadHue）、导出（PNG / PDF / ZIP / 项目文件）、分享、换色板、套装档位、制作规格等业务逻辑保留并复用，必要时拆分组件但不改变行为（相关单元测试须继续通过）。
- 顶栏：返回（`/me`）、设计名（点击改名）、保存状态（已保存 / 保存中 / 失败可重试、本机 / 云端）、居中「编辑 | 跟拼」、撤销重做、「分享」弹出层（复制只读链接、公开到豆社…）、主按钮「导出」菜单（下载 PNG…弹窗、打印 PDF…、导出项目文件、采购清单）、「…」（复制为新设计、快捷键说明、删除设计）、右面板开关。
- 左工具栏：手形、画笔（笔刷大小浮层）、橡皮、油漆桶、吸管、替换颜色；快捷键 H/B/E/G/I/R、撤销重做、+/-/0、空格平移。
- 画布：居中适配、缩放（滚轮以指针为中心、按钮）、平移、网格 / 板缝 / 色号切换（色号随格宽出现）、悬停坐标与色号提示、左上尺寸胶囊；底部浮动缩放胶囊。沿用 D5 / D8 的移动端安全约束（导航手势不写图）。
- 原图参照：右上角胶囊；浮窗可拖动 / 缩放 / 折叠，单向跟随画布（BeadHue 几何）；无可靠对应时黄色提示胶囊，点击说明 +「选择原图」。
- 右面板：颜色（当前色、换色板确认、图纸用色列表带颗数与替换 / 高亮、全部颜色搜索）、调整（有原图时的生成参数与重新生成确认、旋转 / 镜像；无原图时空状态卡）、信息（尺寸、颗数、底板示意、采购清单与复制）。
- 公开到豆社弹窗（D72）：标题、建议标签（D68）、原图同意与发布权两个勾选框、提交审核；引用来的图纸与已公开的按原型禁用并说明。
- 1024–1279 宽度的面板与工具栏收紧规则照原型。

## 验收

- 与原型截图在 1440 / 1024 一致；E2E 02、04、09、11、18-workbench 中编辑器相关用例更新并通过（Chromium）；性能测试不退化。门禁全绿。
