## 恢复方法（主会话被截断后）

1. 看本表与各票头的 `Completion:`；`git log --oneline` 看已提交的票。
2. 「进行中」的票：用 Task `resume` 发一句「继续」试探；返回「currently running」说明仍在跑，不要重复派发。
3. 子代理的完成通知可能不送达：读 `agent-transcripts/<会话>/subagents/<id>.jsonl` 末尾的最终回报与 `turn_ended` 状态。
4. 票 02 完成后：在主工作区 `git merge --no-ff <它的分支>`，解决冲突，跑 typecheck / lint / 受影响测试，再派发票 03。
