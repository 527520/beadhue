# 豆色绘前端现状审查

Status: ready-for-human
日期：2026-09-23 · 分支 `feat/beadhue-ui-rebuild`（基于 `feat/beadhue-redesign` 13482f7，正在合入 r14 3400885）

## 走查方法

- 本地 `next dev`（内存 PGlite + E2E 种子，`BEADHUE_*` 环境变量），另写入 12 件官方样例作品、11 个标签、7 个点赞、4 份云端设计。Chromium，桌面 1440×900，手机 390×844（isMobile + 触屏）。
- 用户端截图 67 张在 `evidence/current/`，局部放大在 `evidence/crops/`；脚本 `tools/capture-current.mjs` 可复跑。
- 后台：BeadHue 分支的后台只改了品牌，合入 r14 后以 r14 版本为准，所以后台部分沿用 r14 的截图（`evidence/main-r14/`）。main 上旧版莓果界面的截图也保留在那里，仅作对照。
- 不计入缺陷的开发环境噪声：左下角 Next.js「N」徽标与 Compiling 提示；整页截图里固定底栏出现在页面中部是截图拼接造成的。

共列出 7 条系统性根因、48 处页面问题、7 类跨页面的操作状态问题。

## 一、系统性根因：为什么每一轮改完还是不协调

1. **两层手写样式叠在一起。** 糖果风没有替换旧样式，而是在 3,068 行的 `globals.css` 上又叠了 4,236 行的 `beadhue.css`，用户端合计 7,300 余行。新层靠 `.beadhue-ui .xxx` 的权重去压旧层，但 react-aria 选择器、开关、数字框、日期框等旧组件仍吃 `globals.css`，所以同一页面里新旧两套控件混用。两份文件合计 126 个十六进制色值、72 种字号写法、60 种圆角写法、20 种断点。
2. **没选中的方案也被一起上线。** `beadhue.css` 顶部是原型 A「蓝绿作品馆」的整套令牌（`--brand: #126b63`），第 1435 行起再用 `[data-theme="candy"]` 覆盖成 B 方案；也就是每个颜色都先按 A 算一遍再被 B 覆盖。
3. **主题外壳放错了地方。** 整站的 `<div class="beadhue-ui" data-theme="candy">` 包在统计同意组件 `ConsentPlacement.tsx` 里；弹窗则由 `Modal.tsx` 在运行时查 DOM、把主题类复制到自己的挂载点上。页面样式和弹层样式靠这种耦合对齐，任何一处改动都可能让弹层掉回旧样式。
4. **标题字体子集装不下动态内容。** 糖果风把标题字体设为 `BeadHue Round`（寒蝉全圆体的离线子集），但子集只收录了预设口号里的字。「没有符合这些条件的作品」只有「这、的、作」是圆体，其余回退到系统苹方；「内置品牌色板」只有「色板」是圆体；作品名「橘猫团子」一个字都不在子集里。凡是动态标题都会出现一行两种字体。证据：`crops/empty-search-1440`、`crops/palettes-1440`。
5. **分段控件被当成万能组件。** 主导航（发现 / 创作 / 我的）、编辑器模式（预览 / 编辑 / 跟拼）、设置面板子页签（参数 / 用色 / 导出）都用同一种分段按钮，导航、模式、页签在视觉上无法区分；查看器选项仍是三颗开关；色板页还留着原生 `<select>`，账号页留着原生折叠三角。
6. **信息架构没有跟着「发现优先」一起重排。** 编辑器的模式切换被放进可关闭的「图纸设置」面板；导出、导入、分享、公开混在「导出」子页签里；我的公开作品只是「我的设计」下的一个页签；原图云端空间卡常驻「我的设计」页顶。
7. **说明与口号挤占信息位。** 平台许可条款被当成作品简介显示两次；推荐卡写着固定口号「7 种颜色，给今天加一点小成就。」；搜索框外面漂着一行提示「兔子、花朵，或一点灵感」；触屏上仍显示「鼠标拖动或触屏滑动平移；按 Ctrl/Command + 滚轮缩放」。

## 二、逐页问题

### 1. 全局框架

1. 主导航做成分段按钮组，激活项是实心蓝块，看起来像表单里的单选控件而不是站点导航；「色板」「帮助」是右侧的纯文字链接，与主导航不是一个层级体系。证据：`a01-home-first-visit-1440`。
2. 未登录时右上角也显示一个「我」字头像，看起来像已登录；登录后变成首字母，缺少明确的「登录」入口。证据：`a13-login-validation-390`。
3. 统计同意横幅仍作为内容卡片插在页头下方，桌面约 90px、手机约 240px，把发现页首屏和选图后的裁剪卡整体下推；主色实心按钮用在了「同意匿名统计」上。证据：`a01-home-first-visit-390`、`a16-create-after-pick-1440`。
4. 手机固定底栏遮挡详情页的统计区和列表卡片底部，页面底部没有为底栏留出安全区。证据：`crops/detail-390-a`。

### 2. 发现页（`/`）

1. 首屏被口号和推荐卡占满：眉题 + H1 + 副标题 + 远在右侧的孤立按钮「用自己的图片创作」+ 两张推荐卡。手机首屏一件作品都看不到。证据：`a01-home-first-visit-390`。
2. 两张推荐卡宽度约 6:4、底色一黄一蓝、结构不同（左卡有徽章，右卡有眉题），作品图带满格线和板缝线；文案是与作品无关的固定口号。
3. 搜索框右侧漂着提示文字「兔子、花朵，或一点灵感」，既不是占位符也不是标签；排序是下拉框，「更多筛选」展开成页内面板（作者、制作规格、日期从 / 至 +「应用筛选」），把作品网格整体往下推。证据：`a06-community-filters-open-1440`。
4. 标签区只剩一个实心蓝色「全部」芯片（本分支还没有 r14 的标签筛选），看起来像坏掉的控件。
5. 卡片缩略图仍满铺格线和板缝粗线（32×32 的图在第 29 格处有一条竖线）；缩略图右下角的「→」圆钮与整卡可点重复；手机两列时「32 × 32 · 10 色」被挤成两行。证据：`crops/discover-390-b`。
6. 卡片上的心形只是计数，不能点赞或收藏；作者头像是一个字的色块，不可点。
7. 手机排序面板用方形复选框表示单选（`a07-community-sort-open-390`），且与展开的「更多筛选」面板同时出现。

### 3. 作品详情

1. 查看器放在大面积杏黄底卡片里，橘猫、西瓜这类暖色作品与底色互相干扰；默认开启「色号标注」，首屏是满格 H7 / A7 / F2 文字。证据：`u02-detail-signed-in-1440`。
2. 手机上缩放条跑到黄色卡片外面，图纸框下沿撑出卡片（溢出），三个开关折成两行。证据：`crops/detail-390-a`。
3. 右栏把平台许可条款当作作品简介显示，下方又原样重复一次。
4. 统计口径前后不一：登录后第三项是「498 预计豆量 · 颗」，未登录变成「1024 画布格数」。证据：`crops/detail-anon-1440`。
5. 赞数显示两遍（心形旁的「1」与「1 赞 · 0 次引用」）；举报旗子和「…」是一排没有文字的图标。
6. 讨论区是「表单卡 + 约 160px 高的空白卡」，右栏在讨论区旁整块留空。
7. 没有色号清单与颗数、没有相关作品，作者不可点，看完即到底。

### 4. 创作入口与选图（`/app`）

1. 标题贴页面左边线，上传卡居中约 470px 宽，左右各空约 400px，标题与内容不在一条对齐线上。证据：`a10-create-entry-1440`。
2. 「从空白画布开始」只是卡片底部的一行文字按钮，入口过弱；三张示例图没有说明点下去会发生什么。
3. 选图后的裁剪卡只有约 310px 宽，「生成图纸」按钮落在 900px 高的首屏之外；统计横幅仍压在上方。证据：`a16-create-after-pick-1440`。

### 5. 编辑器

1. 全站导航与编辑器头两层叠加；编辑器仍在普通页面流里，整页会滚动，头部与横幅随之滚走，不是一个固定的工作区。证据：`a17-create-generated-1440`。
2. 模式切换「预览 / 编辑 / 跟拼」放在可关闭的「图纸设置」面板里，关掉面板就找不到模式切换；面板里还有第二层「参数 / 用色 / 导出」。
3. 画笔调色板排在设置面板最底部，要滚动才看得到；当前颜色只在画布顶栏显示色块和色号。
4. 原图参照窗默认浮在画布右上角；没有可靠对应关系时只显示一句错误，却仍然挡着画布。证据：`u06-editor-1440`、`u06-editor-390`。
5. 画布既不居中也不适配视口：桌面图纸贴左上角，手机初始只露出一半。证据：`a17-create-generated-390`。
6. 左侧工具栏把撤销、重做、旋转、镜像与画笔、橡皮混在同一列，工具和命令不分。
7. 头部一行挤着「导出」「本地：已保存 云端：已同步」「保存」（实心主按钮）「公开到豆社」「…」；已经自动保存时，手动「保存」作为主按钮意义不清。
8. 「导出」子页签里下载 PNG、PNG 选项、导出 PDF、导出 / 导入项目文件、分享图纸、公开到豆社宽窄不一地堆在一起；「导入」属于新建，「分享 / 公开」属于发布。证据：`u09-export-open-1440`。
9. 跟拼的进度条、定位窗、底部工具条、提示语分散在四处。

### 6. 我的设计

1. 云端设计全部没有缩略图，只在灰格里写「44 × 44 格」。原因：`DesignsView.tsx` 对只在云端的设计置 `thumbnail: null`，缩略图只来自本机 IndexedDB，换设备或清缓存后整页都是占位框。证据：`u01-my-designs-1440`。
2. 原图云端空间卡常驻页顶（0.0 MB / 2 GB 时也显示），比设计本身还显眼。
3. 每张卡两颗状态标签（「本地：已保存」「● 已同步」）+ 更新时间 +「…」，手机上两颗标签折成两行。证据：`crops/designs-390`。
4. 没有搜索、排序、筛选（草稿 / 跟拼中 / 已公开）；「我的公开作品」只是页签。
5. 空状态是虚线框加第二个「新建设计」主按钮，与页头主按钮重复。证据：`crops/empty-designs-1440`。

### 7. 色板、账号、登录

1. 色板页：标题下紧贴未登录警告；未登录时「自定义色板」主按钮仍可点；内置色板切换是原生 `<select>`；「内置品牌色板」「MARD（豆色绘经典 291 色）」标题字体混排（根因 4）。证据：`crops/palettes-1440`。
2. 账号页：「保存用户名」是全宽实心主按钮，成了全页最重的元素；「账号安全」「注销账号」用原生折叠三角。证据：`crops/account-390`。
3. 登录页：错误以红色横幅出现在表单顶部，出错的邮箱输入框本身没有任何标记；返回链接「首页」没有图标，像一段说明文字。证据：`a13-login-validation-390`。

### 8. 管理后台（合入 r14 后的状态）

1. 左上角徽标仍是旧品牌缩写「DP」；作品管理列表偶发缩略图空白（「橘猫团子」）。证据：`m-admin-works-1440`（current）。
2. 总览只有四张指标卡和一排与侧栏重复的「常用入口」，下方约 60% 空白；第四张卡把「需要关注」塞进数字位。证据：`main-r14/m-admin-1440`。
3. 列表 + 详情双栏里列表栏约 310px 宽，分页器（总数、每页条数、上一页、页码、跳页、下一页）被挤成三行；审核页的跳页输入框被压成 0 宽，只剩「−」和「跳转」。证据：`main-r14/m-admin-works-1440`、`main-r14/m-admin-reviews-1440`。
4. 未选中时右侧约 60% 宽度只有「先在左侧选择一项」；审核页三栏中两栏为空。
5. 页头眉题与侧栏分组重复，说明句过长（人员管理 60 余字）；后台卡片、徽标、分页与用户端是两套观感。

## 三、操作状态问题（跨页面）

1. **焦点**：品牌焦点环只覆盖部分元素；程序聚焦的区域落回浏览器默认蓝框。
2. **选中**：导航、模式、页签、排序都用同一种「实心蓝块」表示选中，层级无法区分；单选面板却用方形复选框。
3. **禁用**：禁用按钮是浅蓝半透明（「发布评论」），与次按钮难以区分；参数面板在无原图时整列灰掉而不是收起并说明。
4. **错误**：登录错误不挂在字段上；原图参照窗把错误当内容常驻在画布上。
5. **空状态**：几乎全是「虚线框 + 图标 + 一句话 + 实心主按钮」，与页面主按钮重复。
6. **弹层**：更多筛选是页内展开而不是弹层；排序在手机是底部面板、在桌面是下拉，两者选项样式不一致；导出不是菜单而是页签。
7. **移动端**：图纸查看器与编辑器初始不适配屏幕；固定底栏遮挡内容；触屏显示鼠标 / 键盘操作说明。
