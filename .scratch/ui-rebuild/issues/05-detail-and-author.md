# 05 作品详情与作者主页

Status: ready-for-agent
Completion: complete
Blocked by: 01、02、03

先读 [实施指南](../implementation-guide.md)。原型：`prototype/js/screens/detail.js` + `styles/screens/detail.css`、`me.js` 中的作者主页部分；截图 `prototype-final/05、06、17` 及 `evidence/prototype/detail-*`。

## 范围

- `/community/[id]` 按原型重建：面包屑、标题行（精选徽标、标签芯片链接到 `/?cat=`、作者头像与名字链接 `/u/[id]`、发布时间、点赞胶囊、分享弹出层（复制链接、保存分享图）、更多（举报 / 自己的作品为复制链接））；查看器（中性舞台、豆粒 / 方格、缩放与平移（按钮、滚轮、双指、双击、键盘）、网格自动出现、色号、板块、全屏查看、工具条在舞台内）；吸顶制作卡（三格统计、规格与底板数、色号清单前 6 项 + 展开、「用这张制作」确认弹窗后走现有引用流程进入编辑器、「下载图纸 PNG」、许可一行 + 弹出层全文）；讨论（输入框在上、评论列表游标分页、自己的评论可删除且二次确认、他人评论可举报、待审核状态提示、空讨论一行邀请）；相似作品（`related` 接口）；作者的更多作品。
- 未登录（D53 / D67）：服务端豆粒大图可缩放拖动，无色号；色号清单模糊并提供登录入口；主按钮「登录后制作」；下载、举报、评论先要求登录。
- 手机：通栏查看器、迷你工具条、折叠色号清单、吸底操作栏（点赞 + 用这张制作），768–1023 同样吸底（只保留一个主按钮）。
- `/u/[publicAuthorId]`：头像、名字、官方徽标、简介（没有则不显示）、统计（作品 · 获赞 · 被引用）、作品网格（游标分页）、空状态、不存在的作者 404 页。

## 验收

- 与原型截图在五个宽度下一致；举报、分享、全屏、许可弹层在桌面为弹出层 / 弹窗、手机为底部面板。
- 更新 E2E 12、16 等涉及详情的用例（Chromium）。门禁全绿。

## Comments

### 实施记录（2026-09-24，分支 `feat/beadhue-r15-05-detail`）

**详情页** `/community/[id]`：`page.tsx` 只取数（作品、相似作品 5 件、作者的更多作品、是否已喜欢、色板名、底板规格、服务端算好的「N 天前」）并组合 `SiteShell` + `DetailView`；界面全部在 `src/components/works/detail/`。
- 标题行：面包屑「发现 / 首个标签」（`discoverHref`）、精选徽标、标签芯片链接 `/?cat=`、作者头像与名字链接 `/u/[id]`（官方带认证图标、头像深墨）、`<time title=完整日期>N 天前发布</time>`、喜欢胶囊（心形 + 数字，`useDetailLike` 乐观更新、未登录先登录再继续）、分享（复制链接 / 保存分享图 1080×1350）、更多（他人作品「举报…」，自己的作品「复制链接」）。菜单 `ActionMenu`：桌面 Base UI 菜单，手机同标题底部面板。
- 查看器 `PatternViewer`：中性舞台、豆粒 / 方格、按钮 / Ctrl·⌘ 滚轮 / 双指 / 双击 / 方向键 +- 0 缩放平移，每格 ≥14px 自动网格，方格且 ≥18px 画色号（打开色号自动切方格并放大到 24px），板块线 + 编号，工具条浮在舞台内（舞台 <600px 只留图标，手机为右下迷你工具条），全屏弹窗共享显示偏好。计算与叠加层在 `lib/render/viewer.ts`，分享图 `lib/render/poster.ts`，画布颜色 `beadTokens.VIEWER_TOKENS`。
- 制作卡：三格统计、「5mm 豆 · 需要 N 块 29×29 底板」、色号清单前 6（手机 5）+「查看全部 N 色」、主按钮「用这张制作」→ 确认弹窗 → 沿用旧引用流程（幂等副本 → 拉到本机 → 交接原图 → `/app?id=&mode=edit`，同步模块按需加载）、「下载图纸 PNG」（复用编辑器 `exportPngBlob`，超限拆图打包）、许可一行 + 弹出层 / 底部面板全文。桌面吸顶；<1024 主操作进吸底栏（喜欢 + 用这张制作）。
- 讨论：输入框在上（自动增高、400 字起显示计数、⌘/Ctrl+Enter 发送），评论最新在前游标分页（新增 `order=desc`），自己的评论更多菜单「删除评论」+ 二次确认，他人「举报…」，自己待审核 / 已隐藏带徽标，锁定提示，空讨论一句邀请。举报弹窗四类原因卡片，「其他」必填说明。
- 未登录（D53 / D67）：查看器绘制服务端豆粒大图（最大放大到原图格宽 2 倍），色号、方格锁定（点了提示登录），网格与板块仍可开；色号清单用色带豆色模糊 + 登录入口；「登录后制作」、下载、举报、评论都先弹登录，登录成功刷新页面并继续原操作（下载等图纸到手后自动开始）。
- **作者主页** `/u/[publicAuthorId]`：头像 xl（手机 56）、名字、官方徽标、简介（仅官方有固定简介，用户账号没有简介字段不显示）、统计「作品 · 获赞 · 被引用」（k / 万）、本人「管理公开作品」、「分享」；作品网格游标分页（链接可无脚本翻页，有脚本就地追加）；空状态；`not-found.tsx` 为「找不到这位作者」+「去发现」。

**后端小改**：`listCommunityComments` / `GET …/comments` 支持 `order=desc`（游标记下方向，混用 400）；修复 `listRelatedCommunityWorks` 对自定义色板作品生成 `order by (false)` 导致整页 500（票 02 遗留，E2E 种子作品就是自定义色板）。

**与原型的有意偏差**
- 未登录没有图纸数据，「方格」与色号一起锁定（原型未登录仍可切方格）；网格与板块线按几何叠加在大图上。
- 举报「不适宜内容」映射到接口分类 `harm`（接口没有合并分类）。
- 相似作品 / 作者作品随首屏服务端渲染（原型为本地数据），作者栏去掉已出现在相似作品里的作品。
- 下载图纸 PNG 用编辑器同一导出（含图例），不是原型的简化图。
- 作者简介：只有官方账号有固定一句；用户账号无简介字段，不显示。
