# 05 作品详情与作者主页

Status: ready-for-agent
Completion: not-started
Blocked by: 01、02、03

先读 [实施指南](../implementation-guide.md)。原型：`prototype/js/screens/detail.js` + `styles/screens/detail.css`、`me.js` 中的作者主页部分；截图 `prototype-final/05、06、17` 及 `evidence/prototype/detail-*`。

## 范围

- `/community/[id]` 按原型重建：面包屑、标题行（精选徽标、标签芯片链接到 `/?cat=`、作者头像与名字链接 `/u/[id]`、发布时间、点赞胶囊、分享弹出层（复制链接、保存分享图）、更多（举报 / 自己的作品为复制链接））；查看器（中性舞台、豆粒 / 方格、缩放与平移（按钮、滚轮、双指、双击、键盘）、网格自动出现、色号、板块、全屏查看、工具条在舞台内）；吸顶制作卡（三格统计、规格与底板数、色号清单前 6 项 + 展开、「用这张制作」确认弹窗后走现有引用流程进入编辑器、「下载图纸 PNG」、许可一行 + 弹出层全文）；讨论（输入框在上、评论列表游标分页、自己的评论可删除且二次确认、他人评论可举报、待审核状态提示、空讨论一行邀请）；相似作品（`related` 接口）；作者的更多作品。
- 未登录（D53 / D67）：服务端豆粒大图可缩放拖动，无色号；色号清单模糊并提供登录入口；主按钮「登录后制作」；下载、举报、评论先要求登录。
- 手机：通栏查看器、迷你工具条、折叠色号清单、吸底操作栏（点赞 + 用这张制作），768–1023 同样吸底（只保留一个主按钮）。
- `/u/[publicAuthorId]`：头像、名字、官方徽标、简介（没有则不显示）、统计（作品 · 获赞 · 被引用）、作品网格（游标分页）、空状态、不存在的作者 404 页。

## 验收

- 与原型截图在五个宽度下一致；举报、分享、全屏、许可弹层在桌面为弹出层 / 弹窗、手机为底部面板。
- 更新 E2E 12、16 等涉及详情的用例（Chromium）。门禁全绿。
