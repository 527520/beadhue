## 范围

- `/me` 布局：头部（头像、昵称、统计来自 `/api/me/stats`、「账号设置」）、链接式页签（设计 · 公开作品 · 喜欢 · 色板），手机紧凑头部与横滑页签。
- **设计**：本机与云端合并列表（沿用 `DesignsView` 的数据与同步逻辑，界面重写）；工具条（实时搜索、状态芯片带数量：全部 / 草稿 / 跟拼中 / 已公开、排序菜单、网格 / 列表切换、「新建」）；卡片用 `thumbnailUrl`（本机未同步的用本地派生预览渲染 `<BeadImage>`），角标只在需要时出现（已公开 / 跟拼进度环 / 仅本机 / 冲突副本）；卡片菜单（打开、重命名、复制、导出项目文件、删除（危险确认））；列表视图；空状态（主「上传图片」+ 次「从空白开始」，此时隐藏工具条）；搜索无结果；原图空间超 80% 才显示横幅。未登录：本机设计 + 登录提示。
- **公开作品**（原 `/community/mine`）：状态徽标（审核中 / 已公开 / 未通过附原因 / 已下架）、菜单（查看公开页、撤回审核、撤回公开（危险确认）、修改后重投）。
- **喜欢**：`/api/community/works/liked`，作品卡网格 + 空状态。
- **色板**：我的色板（卡片、色带、编辑 / 复制 / 删除、新建色板编辑器按原型弹窗）+ 内置色板（卡片 → 可搜索色块弹窗）；`/palettes` 公开页复用内置部分（未登录可看）；工作台「查看完整色板库」的指定图纸流程保留。
- **账号设置**：个人资料（用户名、保存为次按钮且未修改时禁用）、登录与安全（修改密码弹窗、退出其他设备）、原图空间（用量与管理）、隐私（匿名统计开关，沿用现有接口）、危险区域（注销账号，输入用户名确认）。现有账号接口与业务不变。

## 验收

- 与原型截图在五个宽度下一致；所有卡片都有真实缩略图（换设备 / 清缓存后也有）。
- 更新 E2E 04（同步）、01（账号）等受影响用例（Chromium）。门禁全绿。
