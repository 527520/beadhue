## 范围

- `/me` 布局：头部（头像、昵称、统计来自 `/api/me/stats`、「账号设置」）、链接式页签（设计 · 公开作品 · 喜欢 · 色板），手机紧凑头部与横滑页签。
- **设计**：本机与云端合并列表（沿用 `DesignsView` 的数据与同步逻辑，界面重写）；工具条（实时搜索、状态芯片带数量：全部 / 草稿 / 跟拼中 / 已公开、排序菜单、网格 / 列表切换、「新建」）；卡片用 `thumbnailUrl`（本机未同步的用本地派生预览渲染 `<BeadImage>`），角标只在需要时出现（已公开 / 跟拼进度环 / 仅本机 / 冲突副本）；卡片菜单（打开、重命名、复制、导出项目文件、删除（危险确认））；列表视图；空状态（主「上传图片」+ 次「从空白开始」，此时隐藏工具条）；搜索无结果；原图空间超 80% 才显示横幅。未登录：本机设计 + 登录提示。
- **公开作品**（原 `/community/mine`）：状态徽标（审核中 / 已公开 / 未通过附原因 / 已下架）、菜单（查看公开页、撤回审核、撤回公开（危险确认）、修改后重投）。
- **喜欢**：`/api/community/works/liked`，作品卡网格 + 空状态。
- **色板**：我的色板（卡片、色带、编辑 / 复制 / 删除、新建色板编辑器按原型弹窗）+ 内置色板（卡片 → 可搜索色块弹窗）；`/palettes` 公开页复用内置部分（未登录可看）；工作台「查看完整色板库」的指定图纸流程保留。
- **账号设置**：个人资料（用户名、保存为次按钮且未修改时禁用）、登录与安全（修改密码弹窗、退出其他设备）、原图空间（用量与管理）、隐私（匿名统计开关，沿用现有接口）、危险区域（注销账号，输入用户名确认）。现有账号接口与业务不变。

## Comments

### 实施记录（2026-09-24，分支 `feat/beadhue-r15-06-me`）

**布局**：`src/app/me/layout.tsx` 在服务端读登录者（`lib/me/profile.ts`）与 `getMyStats`，传给客户端 `MeShell`；头部（头像、名字、「设计 · 公开 · 获赞」、公开主页 / 账号设置）+ 链接式页签，手机紧凑头部与可横滑页签。页头统计经 `useMe().refreshStats()` 在删除、复制、撤回后重读；设计页加载完用本机 + 云端合并后的数量覆盖「设计 N」。新组件都在 `src/components/me/`（已登记 theme.css `@source` 与 uiScanned）。

**设计**：`use-design-library.ts` 沿用旧 `DesignsView` 的数据与同步（合并、CAS 同步、冲突副本、打开前确认本机图纸与跟拼进度、先删云端再删本机 + 墓碑），另加复制（新 ID、未同步、不带跟拼进度，本机原图随之复制）、导出项目文件、跟拼进度、「已公开」（读 `/api/community/works/mine` 的当前公开修订来源设计）。界面 `designs-panel.tsx`：实时搜索、状态芯片带数量、排序菜单、网格 / 列表（桌面）、新建；筛选写进地址（replaceState）。缩略图：已同步用 `designThumbnailUrl(id, revision)`（服务端豆粒图，换设备也有），未同步用本机图纸 `<BeadImage>`，加载失败回退。角标只在需要时出现（跟拼进度环 / 已公开 / 仅本机或未同步 / 冲突副本）。空状态「上传图片」主按钮 +「从空白开始」，此时隐藏工具条；原图空间超 80% 才显示横幅。

**公开作品**：`own-works-model.ts` 把作品归成审核中 / 已公开 / 未通过（附原因）/ 已下架，另有投稿失败留下的草稿和撤回后待重投；整件撤回的不再显示。菜单：查看公开页、复制链接、打开设计、提交审核、修改后重投、撤回审核 / 撤回草稿 / 撤回公开（危险确认）。撤回与提交沿用旧的幂等命令语义（结果未确认只能重试同一请求，确认前弹窗关不掉）。`listOwnCommunityWorks` 增加喜欢 / 评论 / 引用数与审核时间（只加字段）。

**喜欢**：服务端给第一页，`CommunityWorkCard` 网格，「加载更多」走 `/api/community/works/liked?cursor=`。

**色板**：我的色板（色带卡片、编辑 / 复制 / 删除）、按原型点选的新建 / 编辑弹窗（可切换基准色板；已有色板里不在基准色板中的颜色列为「其他颜色」保留）；内置 13 套卡片 → 可搜索、按色系筛选的色块弹窗（附来源与收录说明）。`/palettes` 公开页复用内置部分，工作台带 `?designId=` 进来时横幅「返回原图纸」、弹窗里「用于当前图纸」→ `/app?id=&palette=`。

**账号设置**：桌面左侧分区导航（滚动高亮）；个人资料（保存为次按钮、未修改时禁用）；登录与安全（邮箱、修改密码弹窗、登录设备与退出其他设备、退出登录）；原图空间（用量、80% 警告、管理原图列表与删除原图）；隐私（匿名统计开关，沿用 `chooseAnalyticsConsent`）；危险区域（注销：输入用户名确认 + 现有接口要求的密码）。新增接口：`GET /api/me/sessions`、`POST /api/me/sessions/revoke-others`（沿用 me 读写限流）、`GET /api/originals/designs`；删除原图沿用 `DELETE /api/designs/:id/original`。

#### 与原型的有意偏差

- 头像「更换颜色」未做：没有存头像颜色的字段，加字段要迁移并改全站头像，超出本票范围。
- 内置色板没有「设为默认色板」：新建设计的默认色板在工作台 / 创作入口里（票 07 / 08），这里只标出实际默认的 MARD。
- 登录设备只写「这台设备 / 其他设备 · 登录时间」：会话表不存设备型号与地点，隐私合同不变。
- 密码行写「修改后其他设备需要重新登录」（没有记录上次修改时间）。
- 注销除输入用户名外仍要当前密码（现有接口要求）；文案按实际业务写明公开作品保留、署名改为「已注销用户」。
- 游客不显示原型的两张「示例」设计；空状态「从空白开始」进入 `/app` 创作入口（工作台没有直达空白画布的地址参数）。
- 服务端缩略图铺满图区（票 02 渲染规则），本机渲染的预览沿用原型 8% 钉板边。
- 账号设置加了「退出登录」一行：手机上没有头像菜单，否则无处退出。
