# ADR-0023：BeadHue 品牌、私人原图与 B 用户端

状态：Accepted，2026-09-22。用户已确认 `.scratch/beadhue-redesign/prototype/` 的 B 方案。

本决策部分取代 ADR-0009 的原图同步边界、ADR-0018 的自动整图首版流程、ADR-0019 的私人原图与公开作品共同生命周期。旧文档保留为历史；当前实现以此文及 `.scratch/beadhue-redesign/spec.md` 为准。

## 决策

- 中文「豆色绘」、英文 BeadHue、工程标识 beadhue。用户端按冻结 B 原型实施发现/创作/我的导航、圆体标题、蓝黄珊瑚配色及移动对照布局。用户 CSS 限定 `.beadhue-ui`；后台保持原视觉。用户随后追加要求全系统按钮取消厚底边、渐变、投影和位移效果，后台按钮同步改成平面样式；此项覆盖冻结 B 原型的立体按钮。
- 选图后先提供可选取景，直接使用整图或确认裁剪才生成图纸；之后仍可重新裁剪。手工编辑被替换前沿用确认机制。
- 登录且已验证账号保存设计时，完整原图独立持久缓存并排队上云。无资格时保存在本机。项目 JSON 只有 SHA-256、可选资产 ID、可选的真实原图显示尺寸与仿射几何关系，没有图片字节。
- 资产不可变，按账号和内容哈希去重；2 × 1024³ 字节独立额度，单图20 MB。私人/公开/官方二进制入口复用资产登记，不因调参、裁剪、自动保存重复上传。
- 原图几何使用浏览器纠正 EXIF 后的显示坐标。画布相机驱动参照窗，不同窗口比例留白；参照窗拖动/扩大不更改相机。几何随旋转、镜像、撤销/重做保存。跨设备恢复原图不生成或覆盖图纸。历史缺少可靠几何时明确提示，不能从缩小源伪造完整原图。
- 设计绑定原图与普通图纸使用相同 revision CAS；服务端核对资产所有者/哈希/尺寸。公开修订冻结哈希，继承与发布都校验一致。引用在授权后得到独立私人资产关联，历史未知尺寸不阻止持有，解码后补齐尺寸且不猜测几何；撤回公开不删除私人资产。
- 删除设计事务内只释放无其他设计关联的私人额度；对象延迟回收，删除前持有原图引用锁并检查所有有效私人/公开引用。替换的旧对象键持久记录在清理表，失败可重试。未关联上传保留24小时供失败重试。账号锁先于作品锁，作品锁先于原图引用锁；最终写入使用锁内最新角色。
- 全二进制入口共享数据库原子分钟/小时计数：账号10/60，IP30/180，无角色豁免。鉴权、资格、限流先于读取正文及 COS；失败与重试计次。429 Retry-After 取所有阻塞窗口最晚恢复时间。客户端串行上传、任务原子认领、账号冷却持久化，取消尚未认领任务不会继续上传。
- 新导出 beadhue-project v3，兼容 doupu-project v3，不兼容v1/v2。浏览器库和偏好先复制验证再记录迁移完成，保留旧数据。旧 Cookie 可续用，新Cookie优先，退出清理两种名称。
- GitHub更名不代表部署。线上数据库、域名、COS与「迟迟」共享网络保持原标识，按迁移指南另行发布。

## 验证边界

本地PGlite和内存对象存储测试验证业务契约；浏览器测试验证界面、IndexedDB与实际画布。真实跨设备、真实COS和生产迁移必须单独记录证据，不能以本地通过代替。
