# 豆色绘前端重构：设计规格

Status: needs-triage（原型评审中，用户确认后再转 PRD 与实施票）
日期：2026-09-23 · 基线 `feat/beadhue-ui-rebuild` · 现状问题见 [audit.md](audit.md)

## 1. 设计参考与取舍

**主参考：Airbnb**（awesome-design-md `airbnb/DESIGN.md`）。它是「以图片为主的社区市场」的范本，与豆色绘的三件事一一对应：
- 类目图标条 + 胶囊搜索 → 发现页的「像素类目条」与全局搜索；
- 照片即卡片、右上角爱心 → 作品卡「图纸即卡片」、右上角点赞；
- 房源详情「左图册 + 右侧吸顶预订卡」→ 作品详情「左图纸 + 右侧吸顶制作卡」（色号清单 + 用这张制作）。

**辅助参考：Pinterest**（`pinterest/DESIGN.md`）只取发现网格的原则：卡片平铺无阴影、图就是卡、间距紧凑、筛选芯片选中即反色。**不取**它的暖奶油底和红色，因为那正是旧版「纸白 + 莓果」的变体。

**编辑器**不照搬任何品牌站点，按专业创作工具的通用做法：固定视口的工作区、左工具栏、居中画布、右属性面板、浮动缩放条。

**签名元素（只在一处用力）：豆粒。** 所有缩略图与详情图默认用「豆粒渲染」：每格画成一颗带孔的圆豆，放在白色钉板上，像真的拼好的作品；编辑时切回方格。类目图标也用 8×8 的豆粒像素画。界面其余部分保持安静。

## 2. 设计令牌

### 颜色（浅色；对比度按 WCAG 计算）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#FFFFFF` | 页面底色、卡片 |
| `--bg-subtle` | `#F7F7F8` | 编辑器画布区、后台页面、查看器底 |
| `--bg-muted` | `#F0F0F2` | 次按钮、默认芯片、输入框悬停 |
| `--bg-emphasis` | `#E4E4E8` | 按下态 |
| `--line` | `#E7E7EA` | 发丝边、分隔线 |
| `--line-strong` | `#D1D1D6` | 输入框边、悬停边 |
| `--ink` | `#1C1C1E` | 标题、正文主色、选中态（17.0:1） |
| `--ink-2` | `#3F3F46` | 正文 |
| `--ink-3` | `#6E6E78` | 次要信息（5.0:1） |
| `--ink-4` | `#9A9AA3` | 占位符、禁用文字（不承载必要信息） |
| `--accent` | `#3160E6` 豆蓝 | 主按钮、链接、焦点环（5.3:1） |
| `--accent-hover` / `--accent-press` | `#2851CC` / `#2145B3` | 主按钮悬停 / 按下 |
| `--accent-soft` | `#EEF3FF` | 主色浅底（极少用） |
| `--heart` | `#E5484D` | 点赞心形（仅图标） |
| `--featured` | `#FFC53D` | 精选徽标底（配深墨字） |
| `--success` / `--warning` / `--danger` | `#17804A` / `#B35C00` / `#CE2C31` | 语义色（文字均 ≥4.5:1） |

强调色纪律：**主色只用于每个视区唯一的主按钮、正文链接和焦点环。** 选中态（类目、页签、芯片、工具）一律用深墨，不用主色。原型右下角可切换主色（豆蓝 / 墨黑 / 番茄）对比，默认豆蓝，与 BeadHue 标志的蓝色一致。

### 字体与字阶

- 正文与标题：`BeadHue Text`（Noto Sans SC 离线子集，可变字重）。**取消圆体做标题**：圆体子集只收录固定口号，动态标题必然混排（审查根因 4）。圆体只用于标志字「豆色绘」。
- 数字与色号：正文字体 + `font-variant-numeric: tabular-nums`；色号 / HEX 用 `ui-monospace`。
- 只允许 7 级字号：

| 级别 | 桌面 | 手机 | 字重 | 用途 |
| --- | --- | --- | --- | --- |
| display | 32/40 | 26/34 | 700 | 创作页标题（全站仅此一处） |
| title-1 | 24/32 | 22/30 | 600 | 页面标题、作品名 |
| title-2 | 20/28 | 18/26 | 600 | 区块标题、弹窗标题 |
| title-3 | 16/24 | 16/24 | 600 | 卡片标题、面板标题 |
| body | 15/24 | 15/24 | 400 | 正文 |
| body-sm | 14/22 | 14/22 | 400 | 次要文字、表格 |
| caption | 12/18 | 12/18 | 500 | 元信息、徽标 |

中文标题统一 `text-wrap: balance`，正文 `text-wrap: pretty`，避免孤字（审查 §2-2）。

### 间距、圆角、阴影、尺寸、动效

- 间距：4px 基数，只用 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64。
- 圆角：`--r-sm 8`（徽标、小色块）、`--r-md 12`（输入框、菜单项）、`--r-lg 16`（卡片、缩略图）、`--r-xl 24`（弹窗、底部面板、查看器）、`--r-full`（按钮、芯片、搜索框、头像、图标按钮）。
- 阴影只有两级：`--shadow-float`（菜单、弹出层、悬停卡片）、`--shadow-dialog`（弹窗、面板）。卡片静置无阴影，靠发丝边或底色区分。
- 控件高度：`sm 32`（工具条、表格行内）、`md 40`（默认）、`lg 48`（手机主操作、搜索框）；触屏（`pointer: coarse`）下 md 自动升到 44。同一行只允许一种高度。
- 动效：按下 120ms、状态 180ms、进出场 240ms，曲线 `cubic-bezier(.2,.8,.2,1)`；只有点赞「豆粒落位」用一次回弹；尊重减少动态。

### 断点与栅格（与 Tailwind v4 默认一致，便于落地）

`sm 640 / md 768 / lg 1024 / xl 1280 / 2xl 1536`。内容最大宽 1280（发现网格在 2xl 放宽到 1440）；页边距 16 / 24 / 32。作品网格列数：<640 两列、640–1023 三列、1024–1279 四列、1280–1535 五列、≥1536 六列；间距手机 12、桌面 20。

## 3. 组件规范（对应 shadcn/ui + Base UI 组件）

| 组件 | 规则 |
| --- | --- |
| Button | primary（主色实心）/ secondary（`--bg-muted` 底）/ outline（白底 + `--line-strong`）/ ghost（无底，悬停 `--bg-muted`）/ danger（仅用于确认弹窗的最终动作）；全部胶囊形；sm/md/lg；可带 Lucide 图标；loading 时图标位换成旋转环，宽度不变；disabled 为 `--bg-muted` 底 + `--ink-4` 字，不用半透明。 |
| IconButton | 圆形，32/40/48；必须有 tooltip 与 aria-label；选中态深墨底白图标。 |
| SearchField | 胶囊，高 48（桌面顶栏 44）；默认 `--bg-muted` 底，聚焦变白底 + 浮起阴影；左侧放大镜、右侧清除；桌面聚焦展开建议面板。 |
| Input / Select / Textarea | 高 40（触屏 44），圆角 12，白底 + `--line-strong`；错误态红边 + 字段下方错误文字（不再用表单顶部横幅）。 |
| Chip | 胶囊，高 32；默认 `--bg-muted`，选中深墨底白字；可带计数；可移除芯片带 ×。 |
| Tabs | 页面级页签用「文字 + 2px 深墨下划线」。 |
| SegmentedControl | 只用于同一视图的模式切换（编辑器「编辑 / 跟拼」、网格 / 列表视图），白色滑块在 `--bg-muted` 槽内。**不再用于导航和排序。** |
| Menu / Popover | 圆角 16、`--shadow-float`、项高 36、左图标右勾选；危险项红字置底并分隔。宽度按内容，最小 200、最大 360，不跟随触发器拉满。 |
| Dialog | 圆角 24、最大宽 480 / 640 / 880；标题 title-2 + 右上关闭；底部按钮右对齐（次在左、主在右）。**手机上自动变底部面板**（Base UI Drawer，带拖动条、吸附档位、软键盘避让）。 |
| Sheet | 桌面后台用右侧抽屉（480px）；手机用底部面板。 |
| Toast | 底部居中深墨胶囊，图标 + 一句话 + 可选动作，4 秒消失。 |
| Badge | 软底 + 同色字：中性 / 信息 / 成功 / 警告 / 危险 / 精选（黄底深墨字）。 |
| Avatar | 圆形；无头像时取首字，底色从豆粒色中按 ID 取。 |
| EmptyState | 豆粒插画（空钉板上几颗豆）+ 标题 + 一句说明 + 最多一个主按钮；若页面已有同一主按钮，空状态只放次按钮。 |
| Skeleton | 与真实卡片同尺寸的灰块，唯一允许循环的动效。 |
| Pagination | 后台表格底部通栏：总数 · 每页条数 · 页码 · 跳页，单行；窄屏只保留「上一页 / 第 n/m 页 / 下一页」。 |

图标统一 **Lucide**：默认 20px、线宽 1.75；密集区 16px。

## 4. 信息架构

- **桌面顶栏**（64px，白底，滚动后出现发丝边）：标志 ｜ 发现 · 创作 · 我的（文字导航 + 下划线）｜ 胶囊搜索（居中偏左，可展开）｜ 右侧：主按钮「上传图片」+ 头像菜单（我的主页、我的设计、色板、账号设置、帮助、隐私、退出；管理员多一项「管理后台」）。未登录时头像位是「登录」次按钮，不再显示一个假的「我」。
- **手机**：页面各自的顶栏（标题 / 搜索图标 / 返回）；底栏「发现 · ＋ · 我的」，中间 ＋ 为圆形主色按钮直达创作；进入详情、编辑器等二级页时隐藏底栏。
- **统计同意**：改为左下角浮动小卡（桌面 360px、手机底栏上方全宽），两个按钮同为次按钮，不占页面流。
- **色板**：移入「我的 · 色板」和编辑器的色板选择器；帮助、关于、隐私进入头像菜单和页脚。
- **编辑器**：独立的全屏工作区，不显示站点导航。

## 5. 逐屏设计与旧问题的对应

编号指 [audit.md](audit.md) 中的条目，例如「§2-1」即「二、逐页问题 → 2. 发现页 → 第 1 条」。

### 5.1 发现（`/`）

- **结构**：顶栏 → 吸顶类目条（像素图标 + 文字，横向滚动，选中深墨下划线；右端「筛选」按钮和「推荐 ▾」排序）→ 作品网格 → 加载更多。首次访问在网格上方显示一行可关闭的新手条「上传一张图片，几秒生成拼豆图纸」。
- **作品卡**：正方形豆粒渲染图，圆角 16；左上「精选 / 官方」徽标，右上白色圆形点赞按钮（点击后心形填红、豆粒落位动效）；下方两行：标题（单行省略）、「作者 · 32×32 · 7 色 + 最多 6 颗用色小圆豆」。去掉「→」圆钮，整卡可点。
- **搜索**：桌面在顶栏，聚焦出建议面板（最近搜索、热门标签、匹配作品、匹配作者），回车进入结果视图（「“猫” · 12 张」+ 清除）；手机点顶栏放大镜进入全屏搜索页。
- **筛选**：桌面为「筛选」按钮下的弹出层，手机为底部面板；内容：尺寸、颜色数、色板品牌、制作规格、发布时间；底部「清除」+「显示 32 张」（实时数量）。已选条件在网格上方以可移除芯片列出。
- **空结果**：豆粒插画 +「没有找到相关图纸」+「清除筛选」次按钮 + 热门标签芯片。
- **解决**：首屏直接是作品（§2-1）；推荐卡口号撤掉（§2-2）；搜索提示进入占位符、筛选改弹层不推开网格（§2-3）；类目条取代孤立的「全部」芯片（§2-4）；缩略图去格线板缝、去重复箭头、元信息单行不折行（§2-5）；卡片可直接点赞（§2-6）；排序面板用单选勾（§2-7）；导航改文字下划线（§1-1）；统计同意不再占首屏（§1-3）。

### 5.2 作品详情（`/works/:id`）

- **桌面**：面包屑「发现 / 动物」→ 标题行（作品名 title-1、标签芯片、作者头像与名字可点、发布日期；右侧「♡ 128」「分享」「…（举报）」）→ 两栏：左 7/12 查看器（`--bg-subtle` 圆角 24，图纸居中适配，底部浮动工具条：缩放、适配、网格、色号、板块、全屏；默认豆粒渲染、不显示色号，放大到每格 ≥14px 时自动出现网格）；右 5/12 吸顶制作卡（尺寸 / 颜色数 / 总颗数三格统计、规格与底板数、色号清单前 6 项带色块与颗数、「查看全部 7 色」展开、主按钮「用这张制作」、次按钮「下载 PNG」、一行「仅限个人制作使用 ⓘ」许可说明）。下方：讨论（输入框在上，空时只一句邀请）、相似作品、作者的更多作品。
- **未登录**：查看器显示服务端大图、适配在舞台内；色号清单模糊并提示「登录后查看完整色号与颗数」，主按钮变「登录后制作」。
- **手机**：顶栏只剩返回、分享、更多；图纸通栏正方形置顶；标题与作者；三格统计；色号清单折叠；讨论；相似作品；底部吸底操作栏「♡」+「用这张制作」；隐藏站点底栏。
- **解决**：查看器底色中性、默认不显示色号（§3-1）；工具条浮在舞台内部、不溢出（§3-2）；许可条款只保留一行链接（§3-3）；统计口径统一为尺寸 / 颜色 / 颗数（§3-4）；赞数只出现在一个按钮上，举报进「…」（§3-5）；讨论空状态一句话、与右栏对齐（§3-6）；新增色号清单、相似作品、作者页（§3-7）；底栏不再遮挡（§1-4）。

### 5.3 创作（`/create`）

- **入口**：居中 880px 单列：display 标题「创作一张拼豆图纸」+ 一句说明 → 大落区卡（白底 + 淡钉板纹理，拖入时描边变主色，主按钮「选择图片」）→ 两块并排次入口：「从空白画布开始」「导入项目文件」→「用示例试试」四张 → 「最近的设计」一行。标题与卡片同一左边线。
- **选图后**：弹出「新建图纸」对话框（桌面 880px：左侧裁剪区，比例预设「原图 / 1:1 / 按底板」；右侧尺寸（1 板 29 / 2 板 58 / 3 板 87 / 自定义）、颜色数、色板、规格与实时小预览；底部固定「取消」「生成图纸」）。手机为全屏两步：裁剪 → 设置面板，主按钮始终吸底。
- **解决**：标题与内容对齐（§4-1）；空白起稿、导入升级为并列入口（§4-2）；「生成图纸」永远在可视区（§4-3）；导入从「导出」页签移出（§5-8）。

### 5.4 编辑器（`/editor/:id`）

- **工作区**：100dvh 固定布局，无站点导航。顶栏 56px：返回 ｜ 设计名（点击改名）+ 保存状态（云图标 +「已保存」，失败时红色可重试）｜ 居中「编辑 | 跟拼」分段 ｜ 撤销、重做 ｜「分享」（弹出：复制只读链接 / 公开到豆社…）｜ 主按钮「导出 ▾」（下载 PNG…、打印 PDF…、项目文件）｜「…」（复制为新设计、删除）。
- **左工具栏**：只放绘图工具（手形、画笔、橡皮、油漆桶、吸管、替换颜色），笔刷大小在画笔旁弹出；撤销重做移到顶栏，旋转镜像移到「调整」面板。
- **画布**：居中并适配视口；底部浮动工具条（缩放、适配、网格、板缝、色号）；左上角淡显「44×44 · 10 色」。
- **原图参照**：画布右上角默认是一枚小缩略图胶囊「原图」；点开是可拖动、可缩放、可折叠的浮窗（保留 BeadHue 已确认的单向跟随规则）；没有可靠对应关系时胶囊变成黄色提示「原图未对齐 · 重新选择」，不遮挡画布。手机上点开为上下分屏对照。
- **右面板（320px，可收起）**：页签「颜色 / 调整 / 信息」。颜色：当前色大色块 + 色号 / 名称 / HEX、图纸用色列表（颗数、点选即用、替换）、色板全部颜色（搜索）。调整：生成参数；无原图时只显示一张说明卡和「选择原图」按钮，不再整列灰掉。信息：尺寸、颗数、底板数、采购清单与「复制清单」。
- **跟拼**：画布高亮当前板与行；右面板变为进度（百分比 + 板块总览）、当前行、「完成本行」主按钮、上一行 / 下一行、回到下一处未完成；清空进度进「…」。
- **手机**：顶栏「返回 ｜ 编辑 / 跟拼 ｜ 撤销 重做 ｜ …」；画布全屏适配；底部工具栏（5 个工具 + 当前色块）上方一条最近用色；调整、信息、导出、分享从「…」以底部面板打开。
- **解决**：去掉双层头部、固定工作区（§5-1）；模式切换回到顶栏且唯一（§5-2）；调色板成为默认面板（§5-3）；原图错误不再遮挡画布（§5-4）；画布居中适配（§5-5）；工具与命令分开（§5-6）；头部只留一个主按钮，自动保存以状态文字呈现（§5-7）；导出 / 分享 / 公开分开（§5-8）；跟拼信息集中在右面板（§5-9）。

### 5.5 我的（`/me`）

- **头部**：头像、昵称、统计（设计 · 公开 · 获赞）、「账号设置」。页签：设计 · 公开作品 · 喜欢 · 色板。
- **设计页签**：工具条（搜索、状态芯片「全部 / 草稿 / 跟拼中 / 已公开」、排序、网格 / 列表切换、「新建」）；卡片为服务端渲染缩略图，角标只在需要时出现（「仅本机」云朵斜杠、跟拼进度环、「已公开」）；下方「名称」与「44×44 · 10 色 · 2 小时前」；悬停出现「…」（打开、重命名、复制、导出、删除）。
- **原图空间**：移入头像菜单和账号设置，用量超过 80% 才在页顶提示。
- **空状态**：豆粒插画 +「还没有设计」+ 主按钮「上传图片」+ 次按钮「从空白开始」；此时工具条的「新建」隐藏，避免两个主按钮。
- **解决**：缩略图（§6-1，需新接口）；空间卡降级（§6-2）；状态标签合并为角标（§6-3）；搜索 / 筛选 / 排序（§6-4）；空状态主按钮唯一（§6-5）。

### 5.6 管理后台（`/admin`）

- **外壳**：与用户端同一套令牌的浅色侧栏（可折叠为图标栏），徽标换成新标志；顶栏面包屑 + 全局搜索。
- **总览**：四张紧凑指标卡（带 7 日迷你趋势）+「待办」列表（跨队列前 5 项，可直接进入）+ 7 日趋势图 + 服务状态。
- **列表页**（作品、评论、举报、人员、标签、批次、日志）：通栏数据表格（TanStack Table），工具条放搜索与筛选，选中行出现批量操作条；底部单行分页；点击行从右侧滑出详情抽屉，而不是常驻一个空的右栏。
- **审核台**：左侧队列、右侧审核区（图纸与原图并排、决定与理由）；进入时自动选中第一项；快捷键 J / K 切换、A 通过、R 驳回。
- **解决**：旧标志（§8-1）；总览空白（§8-2）；分页挤压（§8-3）；空右栏（§8-4）；页头冗余与两套观感（§8-5）。

### 5.7 跨页面状态（对应审查第三部分）

焦点环统一 2px 主色 + 2px 白色间隔，覆盖所有可聚焦元素（含程序聚焦区域）；选中态统一深墨；禁用态不用半透明；字段级错误；空状态主按钮唯一；弹层按内容定宽，桌面弹出层 / 手机底部面板由同一组件自动切换；触屏不显示鼠标键盘说明（改为 tooltip 与帮助页）。

## 7. 组件库落地方案（建议，待确认）

- **shadcn/ui（Base UI 原语）+ Tailwind v4 + Lucide**，用户端与后台统一。零运行时样式，天然满足现有 nonce CSP（禁止运行时注入 `<style>`）；组件源码进仓库可逐个精修；Base UI Drawer 自带手势、吸附档位和软键盘避让，正好承担「桌面弹层 / 手机底部面板」；后台表格用 TanStack Table。
- 令牌写进 Tailwind v4 `@theme`，组件只用令牌；`globals.css` 与 `beadhue.css` 最终删除，只保留令牌、字体、极少量全局规则（目标 < 300 行），新增 lint 规则禁止组件里出现十六进制色值和任意字号。
- 备选：Ant Design v6 zeroRuntime 模式（后台更省事，但用户端需要大量覆盖，手机弹层偏弱）。
