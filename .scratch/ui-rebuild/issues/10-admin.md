## 范围

- 外壳：浅色侧栏（新标志 +「管理后台」、分组导航、待办计数、可折叠为图标栏、768–1023 默认图标栏、手机抽屉）、顶栏（面包屑、搜索、头像菜单）、页面标题 + 一句说明（去掉眉题）；后台不显示统计同意。
- 总览：四张指标卡（7 日迷你趋势、较昨日变化、可点进）、待办（跨队列前 5）、近 7 天趋势图（`overview/trends`）、服务状态。
- 通用数据表格（TanStack Table 或等价实现 + Base UI）：工具条（搜索、筛选弹出层、排序、导出）、行选择与批量操作条、通栏单行分页（总数 · 每页 · 页码 · 跳页；窄屏简化；沿用 r14 的每页条数记忆）、行点击右侧抽屉（手机底部面板）；手机表格变卡片列表。
- 各模块沿用现有 API 与业务（理由 ≥3 字、确认、审计、幂等键）：作品管理（标签编辑、精选、锁评、下架 / 恢复）、作品审核（进入自动选中第一项、图纸与原图等高并排、核对清单、建议标签一键采纳（D68）、J / K / A / R 快捷键、空队列）、评论治理、举报案件、标签管理（含 `icon` 像素编辑器、`sortOrder`、`featured`）、官方批次（四步流程与 r14 的草稿再编辑，界面换新）、人员管理、匿名分析、审计记录、运行日志、系统信息。
- 删除后台对旧 `AdminPrimitives` 等组件的依赖（文件留给票 13）。
