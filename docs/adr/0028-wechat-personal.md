# ADR-0028：个人主体微信小程序与 Web 共用私人数据

日期：2026-09-29。状态：接受，实施中。

用户确认首版是个人图片处理工具，不承载公开 UGC。采用 apps/weapp 原生 Taro 前端，共用现有 Next.js 服务和数据库，独立 React 18 与 Web React 19。共享核心保留单一来源，平台 I/O 分开；使用 Web 手机端 main 9a95b456 的视觉规范。

微信身份绑定已验证邮箱账号，以 (appid,openid) 和 (appid,userId) 两个唯一约束管理。会话明确区分 web/weapp，Bearer 必须查库验证会话类型并命中私人 API 允许表，不能绕过 Web Cookie 的 Origin 防护。公共 mini 认证入口复用原限流、口令和邮件规则。解绑吊销 mini 会话，账号注销删除微信绑定。

本地保存先于云同步；文件提交中断应保留旧设计。不同身份目录隔离，游客迁入需用户确认。CAS 冲突仍创建副本。跟拼进度仅本地，不进项目 v3 或云协议。

云开发不是个人主体一概不可用，但本产品无云函数依赖。域名备案、独立小程序备案和 AppID 是发布门槛，不能以调试时关闭域名校验替代。公开社区只在 Web，帮助页明确提供主动复制网站地址。

影响：需额外维护平台 I/O、原生组件和真机视觉证据；业务算法、规则与后端仍共享。详见 .scratch/wechat-miniprogram/spec.md 和 apps/weapp/README.md。
