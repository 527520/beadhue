# 07 创作入口与新建图纸

Status: ready-for-agent
Completion: not-started
Blocked by: 01、03

先读 [实施指南](../implementation-guide.md)。原型：`prototype/js/screens/create.js` + `styles/screens/create.css`（以及 `editor/source.js`、`catalog.js` 中与新建相关的逻辑）；截图 `prototype-final/07、08`、`evidence/prototype/ce-create*`。

## 范围

- `/app`（无 `id` 时）：居中 880px 单列；display 标题 + 说明；大落区（拖入态主色描边与钉点、键盘可达、非图片文件在落区内说明原因）；并列次入口「从空白画布开始」「导入项目文件」；「用示例试试」（内置几张示例插画，点开走同一新建流程）；「最近的设计」；隐私说明一行。
- 「新建图纸」弹窗：左裁剪（可拖动与缩放的取景框，比例「原图 / 1:1 / 按底板」）、右设置（图纸宽度芯片 1/2/3 板 + 自定义、颜色数滑杆、色板选择、制作规格、去背景开关、结果预览：尺寸 · 颗数 · 颜色数）；底部固定「取消」「生成图纸」；手机为底部面板、按钮吸底。生成沿用现有 Worker 管线与进度 / 取消（D35），生成完成进入编辑器（`/app?id=`）。HEIC、EXIF、超大图、动图等边界处理与错误文案沿用现有逻辑，换成新组件呈现。
- 「新建空白画布」弹窗（尺寸、色板、规格）沿用 D42 逻辑；「导入项目文件」沿用现有导入（兼容旧格式）。
- BeadHue 已有的原图保存（登录后原图自动存私人空间）在新建流程中保持。

## 验收

- 与原型截图在五个宽度下一致；E2E 02、03、05、07、10、13 中的上传 / 裁剪 / 生成流程更新并通过（Chromium）。门禁全绿。
